# Habit Hourglass

一個零後端、可離線使用的習慣打卡器，提供日曆回顧和（可關閉的）獎勵點數功能。資料存在瀏覽器的 localStorage。

網址：https://proudfish07.github.io/habitat/

## 功能

- **今天**：點圓圈打卡，同一天再點一次就取消。每個習慣會顯示目前連續天數和本週進度。
- **日曆**：可以看「全部習慣」或只看單一習慣。
  - **週**：表格呈現，直接在格子裡打勾。
  - **月**：「全部習慣」模式用彩色小點標出每天完成了哪些習慣；單一習慣模式把完成的日子整格上色，連續的天數會連在一起。
  - **年**：熱力圖，顏色越深代表當天完成的習慣比例越高。
  - 點任何一天都可以**補登或修改**當天的紀錄（未來的日子不能記）。
- **單一習慣統計**：目前連續天數、最長連續天數、本月達成率、累計天數。設定成每週 N 次的習慣，會改顯示本週進度和連續達標週數。
- **每週目標**：每個習慣可以設成「每天」或「每週 1–6 次」。
- **獎勵／懲罰**（**預設關閉**，需要時到「設定」開啟；關閉時點數資料仍會保留）：
  - 計次：每次固定加分。
  - 累計：分數 × 連續天數，最多 ×30。
  - 懲罰會扣分。
  - 每張獎勵卡可以自訂由哪些習慣、哪些懲罰計分。
  - 兌換或新開一期時**不會刪除任何打卡紀錄**，只會重新計算點數。
- **封存**：不再追蹤的習慣可以封存，歷史紀錄仍會保留在日曆上。
- **備份**：可以匯出／匯入 JSON（也能匯入舊版格式）。
- **PWA**：可以安裝到手機桌面，離線也能使用；會跟隨系統切換深色模式。

## 資料保存

- 資料存在 localStorage，key 為 `habit_hourglass_v2`。
- 第一次開啟新版時，會自動讀取舊版的 `habit_rewards_v1` 並轉換。**舊 key 不會被刪除**，可以當作備份。
- 匯入 JSON 之前，會先把目前的資料備份到 `habit_hourglass_v2_before_import`。
- 清除瀏覽器資料或更換裝置，資料就會遺失，請定期在「設定 → 匯出 JSON」做備份。

## 開發

```bash
npm install       # 第一次
npm test          # 邏輯單元測試（遷移、連續天數、計分）
npm run build     # src/ → app.js，並自動更新 service worker 快取版本
```

- `src/lib.js`：純邏輯，包含日期、資料結構、遷移、計分和統計
- `src/app.jsx`：畫面（React 18.3.1）
- `styles.css`：樣式
- `app.js`：**建置產物，請勿手動修改**。GitHub Pages 直接使用這個檔案，所以要一起 commit。

修改 `src/` 之後要執行 `npm run build`，再把 `app.js` 和 `service-worker.js` 一起 commit。
